# Obsidian and Quartz

Obsidian edits a folder of markdown. Quartz turns that same folder into a static site with
backlinks, a graph view and full-text search.

## The nice property

The source of truth stays plain markdown on disk. No database, no lock-in — the site is a
*view*, and if the tooling disappears the notes are still just files.
