# A Note With A Deliberately Long Title That Should Wrap Awkwardly On Narrow Screens

This exists to break things on purpose.

The title is long, so the header has to cope. The filename is long, so breadcrumbs and explorer
entries are long. The `description` is long, so the properties table has to wrap. A layout that
survives this note survives most real ones.
